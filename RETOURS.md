# Retours d'expérience

Ce projet est jeune (version 0.3, fonctionnelle). Il sera forcément amélioré —
et pour qu'il aille dans la bonne direction, votre regard compte vraiment.

Que vous l'ayez **testé**, simplement **parcouru**, ou que vous travailliez dans
l'accessibilité, le BIM ou le bâtiment : tout retour m'intéresse.

## Ce qui m'aide particulièrement

- Vous l'avez essayé sur un fichier IFC ? Qu'est-ce qui a marché, qu'est-ce qui a coincé ?
- Quelque chose vous paraît faux, imprécis, ou incomplet ?
- Il manque une vérification, une fonction, un cas d'usage que vous rencontrez sur le terrain ?
- Le projet vous semble-t-il clair, compréhensible, utile ?
- Vous êtes auditeur, architecte, ou personne concernée : votre expérience vaut de l'or.

Les critiques honnêtes sont les bienvenues. Un projet ne progresse pas avec des
compliments, mais avec des retours sincères.

## Comment me faire un retour

- **Sur GitHub** : ouvrez une *issue* (onglet « Issues » du dépôt). C'est l'idéal
  pour signaler un problème ou proposer une amélioration, et ça reste tracé.
- **Sur LinkedIn** : si vous préférez un échange plus direct, écrivez-moi ici :
  https://fr.linkedin.com/in/kévin-chatellard-aa2317188

Merci d'avance pour le temps que vous prendrez. Chaque retour fait avancer le projet.
